# Car Rental App

Тестовий проєкт фронтенд-частини вебзастосунку для оренди автомобілів **RentalCar**, розроблений за макетом у Figma та підключений до бекенду.

## Основний функціонал

- **Домашня сторінка (`/`)**: вітальна hero-секція з швидким переходом до каталогу.
- **Сторінка каталогу (`/catalog`)**: перелік авто з пагінацією типу _Load More_ (на базі TanStack Query) та фільтрацією за брендами, ціною та пробігом.
- **Сторінка деталей (`/catalog/[carId]`)**: повна інформація про автомобіль та інтерактивна форма оренди з нотифікацією.

## Технологічний стек

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **State & Data Fetching:** TanStack Query (React Query), Axios
- **Styling:** CSS Modules
- **Deployment:** Vercel

## Інструкція зі встановлення та запуск

Клонуйте репозиторій:
git clone <посилання-на-репозиторій>
cd 09_FP_Test-Task-Rental-Car

Встановіть залежності:
npm install

Запустіть проєкт у режимі розробки:
npm run dev

Відкрийте у браузері http://localhost:3000.
